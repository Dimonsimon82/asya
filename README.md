# Ася — самодельный мессенджер в стиле старых пейджеров

Свой веб-мессенджер с UIN-номерами, списком контактов, статусами, офлайн-доставкой
и передачей файлов. Это оригинальная программа, а не копия ICQ: код, оформление и звук
написаны с нуля.

## Как получить Asya.exe (без установки Python)

1. Зарегистрируйтесь на https://github.com (бесплатно) и создайте новый репозиторий
   (кнопка New, имя любое, например `asya`).
2. Загрузите в него все файлы этой папки: «Add file → Upload files», перетащите
   `server.py`, `README.md`, `.gitignore` и папку `static`. Нажмите Commit.
3. Скрытую папку `.github` браузер часто не загружает. Поэтому создайте файл вручную:
   «Add file → Create new file», в поле имени введите `.github/workflows/build.yml`
   (косые черты создадут папки), вставьте содержимое файла `.github/workflows/build.yml`
   из архива и нажмите Commit.
4. Откройте вкладку **Actions**. Сборка запустится сама (если нет — выберите
   «Сборка Asya.exe → Run workflow»). Через 2–3 минуты она станет с зелёной галочкой.
5. Откройте завершённую сборку, внизу в разделе **Artifacts** скачайте `Asya-windows`.
   Внутри будет `Asya.exe`.

## Запуск Asya.exe

Положите `Asya.exe` в отдельную папку и запустите двойным щелчком. Откроется чёрное окно
(это и есть сервер, его не закрывайте) и страница мессенджера в браузере. Рядом с файлом
появится папка `data` с вашими сообщениями и файлами.

Windows может показать предупреждение «Защитник Windows предотвратил запуск» (программа не
подписана сертификатом). Нажмите «Подробнее → Выполнить в любом случае». Файл вы собрали сами
из этого кода, поэтому ему можно доверять. Если Брандмауэр спросит про доступ к сети, для
работы только на своём компьютере разрешать не обязательно.

Чтобы пользоваться с другого устройства в той же сети, запускайте из командной строки:

    Asya.exe --host 0.0.0.0

и откройте `http://<адрес-компьютера>:8765`.

## Запуск из исходников (если есть Python 3.8+)

    python3 server.py

Откройте http://127.0.0.1:8765 в браузере.

## Возможности

- Регистрация: сервер выдаёт девятизначный UIN, пароль хранится только в виде PBKDF2-хеша.
- Список контактов: добавление по UIN, удаление, значки непрочитанных.
- Статусы: в сети, отошёл, не беспокоить, невидимка; «не в сети» определяется автоматически.
- Личные сообщения с историей и офлайн-доставкой (сообщение ждёт, пока адресат войдёт).
- Передача файлов до 25 МБ; скачать файл могут только отправитель и получатель.
- Звук нового сообщения (синтезируется в браузере), кнопка «Звук».
- Адаптивная вёрстка: на телефоне список и чат открываются по очереди.

## Важно знать

- Соединение идёт по обычному HTTP. Для работы через интернет поставьте перед сервером
  HTTPS-прокси (nginx, Caddy), иначе пароли и сообщения идут открытым текстом.
- Все данные лежат в папке `data/` (база `chat.db` и загруженные файлы). Копия папки — резервная копия.
- Сообщения не шифруются на сервере: администратор сервера может их прочитать.
- Контакт добавляется односторонне; при первом сообщении собеседники автоматически
  попадают в списки друг друга.
